这场一小时的线上分享将介绍如何设计在高负载下依然稳定的 API。我们会讨论超时、重试、幂等性和真正有助于值班响应的可观测性信号，并进行在线问答。

## 适合人群

- 负责公共或合作伙伴 API 的后端与平台工程师
- 希望避免级联超时并建立清晰实践方案的团队成员

## 你将学到

| 主题 | 收获 |
| --- | --- |
| **超时与重试** | 选择安全的默认值，避免重试风暴 |
| **可观测性** | 关联追踪、指标和服务目标 |
| **事故复盘** | 将生产经验转化为可执行的改进 |
