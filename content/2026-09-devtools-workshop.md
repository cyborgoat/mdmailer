A 90-minute working session for anyone shipping with the toolchain. Bring a laptop
with **Node 24** installed — we'll build a small integration together and leave with
something that runs.

## Who it's for

- Engineers wiring the CLI into a pipeline for the first time
- Anyone who tried it, got stuck, and wants a second pass with help in the room

## Before you arrive

1. Install Node 24 (`node --version` should print `v24.x` or newer).
2. Clone the starter repo from the registration page.
3. Run `npm install` once so the first exercise isn't a waiting game.

> Seats are capped at 20 so everyone gets hands-on time. Can't make it? The
> recording and notes go out to everyone who registers.
