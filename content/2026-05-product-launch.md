# Workspaces 2.0 is live

After three months of beta feedback, **Workspaces 2.0** is rolling out to all customers today. This release focuses on speed, collaboration, and fewer surprises.

## What's new

- Real-time multi-user editing, powered by the new sync engine
- Redesigned sidebar with pinned views and quick search
- Bulk actions on tasks, comments, and attachments
- Dark mode, finally

## Rollout plan

| Segment | Start date | Status |
| --- | --- | --- |
| Internal dogfood | Feb 3 | Complete |
| Beta customers | Mar 10 | Complete |
| Free tier | May 14 | *In progress* |
| Enterprise | Jun 1 | Scheduled |

## Known issues

- [x] Sidebar occasionally flickers on first load — fixed in `v2.0.1`
- [x] Search index rebuild can lag behind by a few seconds
- [ ] CSV export drops timezone info — fix targeted for `v2.0.3`

We track all of these publicly; see the [release notes](https://example.com/changelog) for details.

> Heads up: the legacy workspace UI will be removed on **July 1**. Export anything you still need before then.
